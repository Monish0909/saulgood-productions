# SaulGood Productions Website
Hospitality photography, cinematic videography and aerial studio website.
Stack: Next.js + TypeScript + Tailwind + GSAP + Lenis.
Themes: light editorial (A), dark cinematic (B), switched via data-theme.
Process: Stitch (visual reference) → Antigravity (build steps B0–B9 in docs/prompts.md, one at a time) → Claude (QA).
The web app will be created in a /web folder at step B0.
